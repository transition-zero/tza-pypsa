# TZ-Analysis-PyPSA: India
This folder contains the constructor files used to create a PyPSA model for country of India

PyPSA-India is an hourly-resolution power sector model. It can be used for:

- Dynamic dispatch modelling of power systems.
- Market pricing and intervention analysis.
- Power system capacity expansion planning.

## Overview
The PyPSA-India model is comprised of 5 nodes and 6 [to be updated with interconnectors] links. Here, each node represents a regional power grid in the India National Grid, while each link represents the aggregated transmissions capacity between grid zones.
